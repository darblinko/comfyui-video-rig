# presenter_kitchen_v1

A synthetic presenter persona generated from a text prompt. This folder is the
persona's single source of truth once a look is locked:

- `bible.md` — the exact character description used in every prompt (copy it
  verbatim into video prompts; identity consistency comes from repeating it)
- `ref_*.png` — the chosen canonical reference stills (front, 3/4, expression)
  generated by `jobs/examples/persona_ref.toml`

Later phases train a persona LoRA from these refs; for the POC, prompt
repetition plus the start-frame pipeline carries identity.
